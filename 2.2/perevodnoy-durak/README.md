# Переводной дурак — механика (2-й этап)

Реализация механики карточной игры **Переводной дурак** на Java.

## Правила (кратко)

- Колода 36 карт (6–туз).
- Раздача по 6 карт. Козырь — масть нижней карты колоды (карта остаётся открытой).
- Первый ход — у владельца младшего козыря.
- **Атака**: карты одного достоинства (не больше, чем карт у защищающегося).
- **Защита**: старшей картой той же масти или козырем.
- **Перевод** (отличие от подкидного): защищающийся может положить карту того же достоинства и передать ход следующему игроку.
  - Запрещён в первом раунде.
  - Возможен только до начала отбоя.
  - Число карт на столе + 1 ≤ число карт у следующего игрока.
- **Подкидывание**: карты достоинств, уже лежащих на столе, не больше оставшихся карт защищающегося.
- Цель — избавиться от карт. Последний с картами — «дурак».

## Архитектура

```
ru.durak
├── model/          # предметная область (Card, Rank, Suit, Player, GameState, Move, Event…)
├── game/           # правила (GameEngine), стратегии ботов (Strategy)
└── console/        # слой вывода и точка входа (не используется механикой)
```

**Отделение правил от вывода.**  
`GameEngine` ничего не печатает. Он возвращает `List<GameEvent>`.  
Консольный вывод — только в `ConsoleView`.

**Воспроизводимость.**  
Все случайные величины берутся из одного `Random` с задаваемым зерном.

**Паттерн Strategy.**  
`PlayerStrategy` — выбор хода. Реализации: `RandomStrategy`, `GreedyStrategy`, `HumanStrategy`.

**Компараторы.**  
`CardComparator` — сравнение карт с учётом козыря, метод `beats()`.

## Сборка и запуск

```bash
mvn clean test          # тесты (≥ 20 сценариев)
mvn package             # сборка jar
mvn javadoc:javadoc     # документация

# запуск с зерном
java -jar target/perevodnoy-durak-1.0-SNAPSHOT.jar 42
```

При запуске можно выбрать число игроков и режим (человек / только боты).

## Тесты

JUnit 5. Покрыты:

- граничные ситуации (неверный ход → `IllegalMoveException`);
- полная партия из фиксированного посева;
- компаратор карт;
- воспроизводимость по seed;
- стратегии;
- события без вывода в консоль.
